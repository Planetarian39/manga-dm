## Input and velocity-field context

The Stage 1 fit combines the MaNGA emission-line velocity field with inverse
variance, spaxel masks, projected coordinates, and photometric geometry. The
pipeline deprojects accepted spaxels using the fixed center, position angle,
and inclination, then evaluates the stellar, halo, and pressure-support terms
at those radii. The empirical rotation-curve screen runs before the NFW fit so
that pathological velocity fields do not enter the mass decomposition.

## Posterior diagnostics

The worked example illustrates three different questions:

1. Did independent chains explore consistent posterior regions?
2. What is the joint $M_{200}$-$c$ geometry?
3. How much did the observations update the Stage 1 priors?

For generic definitions, see
[Sampling and diagnostics](/background/mcmc/sampling-and-diagnostics) and
[Diagnostics and quality gates](/methods/diagnostics-and-quality-gates).

## Trace and chain diagnostics

![Eight displayed variables for 11743-9102 show overlapping four-chain marginal distributions and stationary-looking traces; inclination is fixed and appears horizontal.](/assets/case-studies/11743-9102/posterior-trace.png)

*Migrated posterior trace plot for 11743-9102. The left column shows marginal
distributions for four chains; the right column shows retained draws. The
fixed inclination appears as a horizontal line. Exact R-hat and ESS values are
reported in the table below rather than inferred from pixels.*

An ArviZ trace plot puts a marginal distribution beside the chain history:

- **Marginal column:** agreement among chain densities is evidence that the
  chains sampled a common region.
- **Trace column:** stationary-looking, overlapping trajectories are evidence
  against obvious drift or sticking.

The image displays `Mstar`, `M200`, `c`, `v_sys`, `inc`,
`f_bulge`, `sigma_0`, and `Re`. It is not an “all parameter” plot:
`sigma_int` and `nu` are not shown.

### Reading the trace

| Check | Migrated behavior | Interpretation |
|---|---|---|
| Chain marginals overlap | Visible for the sampled variables | No obvious separated chain mode in these marginals |
| Traces are dense without sustained drift | Visible for sampled variables | Qualitative evidence of mixing |
| Inclination is horizontal | Expected | `inc` was fixed from photometry in this fit |
| R-hat and ESS | Use the numerical summary, not visual inference | Quantifies cross-chain agreement and Monte Carlo information |

When `inc_prior_enable=False`, inclination is stored as a deterministic
constant rather than sampled. A flat trace is therefore expected; it is not a
sign of sampler failure.

An equivalent plotting call for the variables shown is:

```python
import arviz as az

az.plot_trace(
    inference_data,
    var_names=[
        "Mstar",
        "M200",
        "c",
        "v_sys",
        "inc",
        "f_bulge",
        "sigma_0",
        "Re",
    ],
)
```

## Joint posterior geometry

![The 11743-9102 joint posterior has a curved negative association between M200 and concentration, with a right-skewed M200 marginal.](/assets/case-studies/11743-9102/m200-c-joint-posterior.png)

*Migrated $M_{200}$-$c$ posterior for 11743-9102. The lower-left contours show
the joint density; diagonal panels show marginal densities and interval
markers. The exact contour probabilities must be confirmed from the original
plot command.*

### Structure of the plot

- The upper-left marginal shows $M_{200}$ and a right-skewed high-mass tail.
- The lower-right marginal shows concentration $c$.
- The lower-left contours show the two-dimensional joint posterior.

The ridge is anti-correlated: larger $M_{200}$ pairs with smaller $c$. At
radii much smaller than $R_{200}$, those changes can compensate in the NFW
velocity profile. The curvature also shows why a mean and covariance are not
always an adequate compression.

To create the same type of diagnostic from an `InferenceData` object:

```python
import arviz as az

az.plot_pair(
    inference_data,
    var_names=["M200", "c"],
    marginals=True,
    kind="kde",
    kde_kwargs={"contourf_kwargs": {"alpha": 0.5}},
)
```

The project uses ArviZ-based plotting for this diagnostic; an additional
plotting dependency is not required.

## Prior-to-posterior update

![For 11743-9102 the migrated prior and posterior for M200 overlap strongly, while the concentration posterior is much narrower than its prior.](/assets/case-studies/11743-9102/m200-c-prior-posterior.png)

*Migrated prior-versus-posterior comparison for 11743-9102. Gray denotes the
prior and blue the posterior. Quantitative narrowing must be recomputed in a
declared parameter space from the finalized posterior artifact.*

### Halo mass

The migrated plot shows substantial overlap between the $M_{200}$ prior and
posterior. This is consistent with limited radial leverage on total halo mass:
the observed velocity field samples only the inner halo.

### Concentration

The concentration posterior is visibly narrower than its broad prior. The
rotation-curve shape provides information about concentration, conditional on
the rest of the model and on the halo-mass prior. “Data-dominated” should not
be read as independence from the prior structure.

The legacy guide described the narrowing both as about fivefold and as about
one tenth in width. Those statements are not retained as facts. The final
case page must compute one metric from the finalized samples, preferably in
$\log_{10}c$ where the prior width is stated in dex.

### Reproduce the comparison

```python
import matplotlib.pyplot as plt
import pymc as pm

with model:
    prior_data = pm.sample_prior_predictive(samples=2000, random_seed=42)

fig, axes = plt.subplots(1, 2, figsize=(10, 4))
for axis, variable in zip(axes, ["M200", "c"]):
    prior = prior_data.prior[variable].values.reshape(-1)
    posterior = inference_data.posterior[variable].values.reshape(-1)
    axis.hist(prior, bins=60, density=True, histtype="step", label="Prior")
    axis.hist(
        posterior,
        bins=60,
        density=True,
        histtype="step",
        linewidth=2,
        label="Posterior",
    )
    axis.set_xlabel(variable)
    axis.legend()
fig.tight_layout()
```

`pm.sample_prior_predictive()` ignores `Potential` terms. That behavior is
appropriate for drawing from the explicitly declared prior, but it should be
stated whenever weighted likelihoods are present.

### Reading the migrated values

- $M_{200}$ has a broad, right-skewed posterior whose shape is similar to the
  Stage 1 halo-mass prior.
- $c$ is more concentrated than its broad prior, conditional on the model and
  other priors.
- $M_\star$ and $R_e$ remain closely tied to photometric information.
- The narrow $V_{\mathrm{sys}}$ posterior reflects direct velocity-field
  information.
- $\sigma_{\mathrm{int}}$ represents residual scatter not captured by the
  measurement errors and deterministic model.
- The migrated $\nu$ value lies in a regime where the Student-t likelihood is
  relatively close to normal for this case.

These are single-galaxy method demonstrations, not population conclusions.

## R-hat and effective sample size

For intuition, classical R-hat compares between-chain and within-chain
variance:

$$
\hat R=\sqrt{\frac{\hat V}{W}}.
$$

Modern ArviZ uses rank-normalized split R-hat, which is more robust than this
simple expression. Values close to one support chain agreement; the quality
gate defines the exact accepted threshold.

Effective sample size translates autocorrelated draws into an approximate
number of independent draws. Bulk and tail ESS answer different questions,
so the final provenance record must state which ESS column appears in the
table.

The migrated maximum R-hat is 1.007 and the listed ESS values are all above
800. Those numbers are promising, but the unresolved provenance warning still
applies: they must be checked against the finalized posterior file.
