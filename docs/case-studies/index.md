# Case studies

Four allowlisted galaxies demonstrate how the same method produces reviewable single-object artifacts. The examples are not a ranked set, a representative population, or evidence for an aggregate relation.

## Deep walkthrough

[11743-9102](/case-studies/11743-9102) connects the model, fit figure, posterior geometry, convergence checks, and complete posterior sample file in one narrative.

## Supporting demonstrations

[8994-12701, 7977-3704, and 9493-6101](/case-studies/supporting-cases) use a common display structure. Each section should be read independently as an example of the fit interface.

## Reproducible assets

The [downloads page](/case-studies/downloads) records the NetCDF schema, exact byte size, SHA-256 digest, and source archive entry for every released file. The aggregate source archive is not published.

::: info Interpretation boundary
Individual posterior summaries are shown only to explain how to inspect stored draws. They are not combined, averaged, ranked, or interpreted as a scientific sample.
:::
